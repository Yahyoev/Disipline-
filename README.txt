Discipline для iPhone — как установить

Это веб-приложение: оно ставится на экран «Домой» iPhone, открывается
во весь экран без адресной строки и работает без интернета.
Все данные хранятся только на твоём телефоне.

ШАГ 1. Выложить файлы в интернет (бесплатно, один раз, ~5 минут)
 1. Зарегистрируйся на https://github.com (бесплатно).
 2. Нажми «+» справа вверху → New repository.
    Repository name: discipline. Выбери Public. Нажми Create repository.
 3. На странице репозитория нажми ссылку «uploading an existing file».
 4. Перетащи туда ВСЕ файлы из этой папки (index.html, sw.js,
    manifest.webmanifest и картинки). Нажми Commit changes.
 5. Открой Settings → Pages. В Branch выбери main и папку / (root) → Save.
 6. Подожди 1–2 минуты. Адрес будет такой:
    https://ТВОЙ-ЛОГИН.github.io/discipline/

ШАГ 2. Поставить на iPhone
 1. Открой этот адрес в Safari (именно Safari).
 2. Нажми «Поделиться» (квадрат со стрелкой) → «На экран „Домой“» → «Добавить».
 3. На экране появится иконка Discipline. Открывай приложение с неё.
 4. Во вкладке «Намаз» нажми «Место → Определить по GPS» и разреши геопозицию.
 5. В настройках (шестерёнка на экране «Сегодня») можно убрать примеры:
    «Начать с чистого листа».

Чего пока нет в этой версии: уведомлений и виджета на экран «Домой».
Они появятся в полноценном приложении, которое собирается на Mac через Xcode.
